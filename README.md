# TNiC — Cell-Health Library (theme preview)

Visual scaffold for [tnic.help](https://tnic.help). This repo **replaced** the old Aether Institute page.

**You do not need bash.** Use the GitHub website.

## Open it (no terminal)

1. Repo: [github.com/tvsnic0419/aether-institute](https://github.com/tvsnic0419/aether-institute)
2. Click a file under `src/` to read the code.
3. To run it in the browser: click the green **Code** button → **Codespaces** → **Create codespace on main**. When the editor loads, GitHub starts the app for you.

The live Grok preview is the same app running already — that is the visual check. This repo is the source backup.
