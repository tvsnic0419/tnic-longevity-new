# TNiC Elite UI & Component Upgrade

This pass raises the quality bar beyond layout optimization by upgrading the reusable surfaces that articulate confidence, choice, evidence, and next steps. The objective is a more refined research-product experience: precise hierarchy, intentionally layered depth, visible interaction affordances, and calm decision-making under information density.

| Upgrade | Component-system change | Applied surface | User-facing effect |
|---|---|---|---|
| Action-card primitive | Introduce a reusable accent-aware action card with layered illumination, clear information hierarchy, and a purposeful action footer. | Stack-start compass and future task-entry surfaces. | Entry choices read as designed paths rather than generic cards. |
| Editorial decision rail | Rebuild the shared three-step orientation component with a recommendation state, stronger progress rhythm, and clearer interaction cues. | Library and product-decision flows. | Visitors immediately understand where to start and what each path leads to. |
| Responsive intent hierarchy | Preserve a single strongly featured route while rendering supporting choices at a quieter visual weight. | Library, products, and stacks. | Better perceived clarity without hiding any educational route. |
| Premium search entry | Upgrade library search with a dedicated research signal, keyboard-friendly visual affordance, and more intentional suggestion treatment. | Library hub. | The research interface feels like a focused instrument rather than a generic input. |
| Evidence-product decision card | Strengthen persistent manufacturer verification affordance and protect evidence, COA, and dose context as a deliberate decision sequence. | Verified product cards. | Purchase-adjacent actions feel transparent, precise, and safer to evaluate. |
| Elevated filter controls | Consolidate repeated selectable states into a consistent selection-pill treatment with visible state and touch-safe interaction. | Product discovery filters. | Faster scanning and a more polished data-exploration experience. |
| Stack handoff surface | Present incoming NICO/elite selections with a richer review state, active data continuity, and decision-gated secondary actions. | Stack Architect. | A visitor arriving with a configuration feels carried forward, not redirected into a new funnel. |
| Focused stack workspace | Keep one builder surface and locate advanced tool discovery after primary configuration work. | Stack Architect. | Less duplicated UI and a clearer path to meaningful task completion. |
| State-aware navigation | Make the global action adapt to whether a local configuration exists and demote a lower-priority route into the structured Explore menu. | Global navigation. | The core action is relevant on both first and returning visits. |
| Motion and accessibility polish | Use restrained hover, press, focus, and reduced-motion-safe affordances at the shared-component level. | All upgraded reusable components. | The interface feels tactile and premium without compromising accessibility or performance. |

The upgrade uses the existing TNiC visual system rather than introducing a conflicting new aesthetic. Accent colors remain purpose-specific, all action targets retain keyboard focus, and external product routing remains subordinate to evidence and safety context.
